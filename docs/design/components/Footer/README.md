# Footer

The bottom band: the same photo treatment as the masthead (the reference uses a brighter, redder crop), carrying a centred row of round contact icons.

- **Spacing:** `space-2xl` (50px) below the main column; `space-l` padding; 1px `rule` along the bottom edge.
- **Icons:** round badges (`radius-round`), single-ink. The reference uses Font Awesome 4.2 brand glyphs (email, GitHub, LinkedIn, Twitter, Stack Overflow, Medium); the preview uses generic placeholder glyphs — swap in the official SVG marks of the services you link to.
- **Accessibility:** every icon link needs an `aria-label`; add a visible focus outline in `on-night`.
- **Provide:** your contact/profile links and a footer photo (or reuse the masthead colour as a flat band).
