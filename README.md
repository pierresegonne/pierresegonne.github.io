# pierresegonne.com

Personal website and blog, built with [Astro](https://astro.build) and deployed to GitHub Pages by GitHub Actions. Design: Navy & Ember (`docs/design/`).

## Setup

Requires Node 24 (`.nvmrc`) and pnpm (version pinned in `package.json`).

```bash
pnpm install
pnpm dev        # http://localhost:4321
```

| Command | What it does |
|---|---|
| `pnpm dev` | Dev server with hot reload |
| `pnpm build` | Type-check (`astro check`) and build to `dist/` |
| `pnpm preview` | Serve `dist/` locally |
| `pnpm check:urls` | Fail if any URL of the old Jekyll site is missing (`scripts/legacy-urls.txt`) |
| `pnpm check:links` | Fail if any internal link or image in `dist/` is broken |
| `pnpm clean` | Delete `dist/` and Astro's caches (see below) |

## Writing a post

Create `src/content/posts/<Slug>/index.md` and put its images next to it:

```markdown
---
title: "My post"
slug: My_post            # the URL: https://pierresegonne.com/My_post/ (case-sensitive)
date: 2026-12-01
description: "Optional. Otherwise the first paragraph is used."
# updated: 2027-01-15
# canonical: https://example.com/original   # if first published elsewhere
# draft: true
---

Text, with maths as in kramdown: $$e^{i\pi} + 1 = 0$$ inline, or a $$ block on its own lines.

:::figure{width="60%"}
![Alt text describing the image](./image.png)

Caption, *Markdown* allowed.
:::
```

Content blocks (`src/plugins/remark-figures.mjs`):

- `:::figure{width="…"}`: a paragraph made only of images is one row, side by side. Other paragraphs form the caption. `width` is optional (defaults to the full column).
- `:::callout`: a boxed aside.
- `:::meta`: a small muted note (footnotes, "last updated", photo credits).

Images are optimised at build time (AVIF/WebP, responsive sizes). Maths is rendered with KaTeX at build time, and only posts that contain `$$` load its stylesheet.

Pages (About, Talks, 404) live in `src/pages/`. Site name, navigation and contact links are in `src/site.ts`.

## Sharing a file by link only

Put the file in `public/resources/share/`. To get a short link like `/Some-name`, add `public/Some-name.html` that redirects to it (copy `public/Pensees-kirghizes.html`). Files in `public/` are not listed in the sitemap.

## Deployment

Every push to `master` runs `.github/workflows/deploy.yml`:
1. install, type-check and build
2. check old URLs and internal links
3. run Lighthouse (budgets in `lighthouserc.json`)
4. deploy to GitHub Pages

Pull requests run the same checks without deploying. The custom domain (`public/CNAME`, `pierresegonne.com`) is set in the repository's Pages settings, with the source set to **GitHub Actions**.

## Notes

- **Stale Markdown after changing a remark/rehype plugin:** Astro caches rendered content. Run `pnpm clean`.
- **Fonts:** IBM Plex is downloaded from Fontsource at build time by Astro's Fonts API, then served from the site itself.
- **Frame images:** `src/assets/frame/{header,footer}.png` are generated by `python3 scripts/generate-frame.py` (numpy, scipy, Pillow). The script is seeded, so it's reproducible.
- **History:** `REFACTOR_PLAN.md` records how the site moved from Jekyll Now to Astro.
